gdrive-ignore

Choose what Google Drive syncs, with .gitignore-style rules

Checking Google Drive…

These rules apply to every folder that has Apply global rules on. They are saved in , so you can also edit them in any text editor.

How it works

Google Drive for Desktop has no way to exclude files. gdrive-ignore keeps a filtered mirror of each source folder inside a folder that Drive syncs, and leaves out everything your rules ignore. Drive then uploads the mirror as usual.

  • Your source folder is only ever read, never changed.
  • When the mirror is on the same drive as the source, files are hardlinked: no extra disk space and no copying.
  • The mirror is one-way. Edit files in the source, not in the mirror.
  • The app only ever deletes files it created itself.

Ignore rules
